# DBマイグレーション（Flyway）

テーブルはここに置いた SQL で作る。アプリを起動すると、まだ実行していない SQL が番号順に自動で実行される。

- ファイル名：`V1__create_tables.sql`、`V2__add_xxx.sql` のように **V＋番号＋アンダースコア2つ＋説明**
- **一度コミットした SQL は書き換えない**（他のメンバーのDBと食い違う）。変更は新しい番号のファイルで行う
- テーブル定義書（設計図/テーブル設計/テーブル定義書_BaitoLog.xlsx）を直したら、ここにも SQL を追加する
- 自分のDBを作り直したいときは、アプリを止めてプロジェクト直下の `data/` フォルダを消す
