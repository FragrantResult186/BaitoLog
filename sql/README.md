# Neonのテーブルとサンプルデータ

## 空のNeonデータベースを準備する

1. Neon Consoleで対象プロジェクト・ブランチを選び、SQL Editorを開く。
2. `create_tables.sql` の内容を実行する。
3. 続けて `sample_data.sql` の内容を実行する。

この初期化は空のデータベースに一度だけ実行します。すでにテーブルや実データがある共有データベースに、初期化SQLや `DROP TABLE` を実行しないでください。
